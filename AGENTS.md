# Comparador de Súper

Web para que personas de Barranquilla comparen precios de supermercado
(Éxito, D1, Olímpica). Estamos en la FASE 1: validar si a la gente le interesa.

## Reglas
- Código simple, claro y comentado, para alguien que está empezando.
- HTML, CSS y JavaScript puro. Sin frameworks, sin librerías, sin compilar.
- Debe funcionar abriendo index.html con doble clic.
- Todos los textos de la interfaz en español.
- No añadir nada que no se pida en el prompt (sin login, carrito, mapas, cuentas).
- Los datos viven en precios.js, separados de la lógica.
